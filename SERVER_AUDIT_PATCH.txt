SERVER.JS — EXACT AUDIT INTEGRATION PATCH

Do NOT replace your full server.js with an older version.
Keep your current working Email Verification + Brevo API + Security server.js.

STEP 1 — Near the top imports, add:

const {
  setupPersistentAudit,
  mountAuditRoutes
} = require("./audit-db");


STEP 2 — Inside createTables(), near the end BEFORE:

console.log("Database ready");

add:

await setupPersistentAudit(pool);


STEP 3 — After the requireAdmin() function is declared, add:

mountAuditRoutes(app, pool, requireAdmin);


STEP 4 — Your existing audit(...) calls will now write to PostgreSQL
as long as security.js has the provided setAuditWriter patch.
